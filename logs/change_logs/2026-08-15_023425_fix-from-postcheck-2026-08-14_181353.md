## Conclusion and decisions

**post-review 最小补丁**：只修复审点名的问题，不顺手重构、不加抽象、不加
flag。两条 OQ 按 `/fix` 采纳的候选落地：

1. **H1 根治 + 止血**：补齐第 5 个返回元素；同时收窄 `except Exception`
   —— 让 `ValueError` / `TypeError` 这类程序错误不再被静默吞成「基础设施
   故障」（这正是 H1 潜伏的原因）。补一条针对 `_settle_one` 成功路径的最小
   回归，该函数目前零测试覆盖。
2. **OQ1 取候选 B**：不可尝试的债（`$` 根锚点且非 unverified）**保持 error
   阻断**，不再零次尝试就写 `given_up(attempts=0)`。理由：零次尝试即放行会
   把「两次机会」在这一支上架空；决策 #74 的放弃语义只应覆盖真跑满两次的债。
3. **OQ2 取候选 A**：`cross_stage_review_unavailable` / `_unparseable` 并入
   「审校没跑成」的规则集，使该判定在任何锚点形态下走同一条路，不再依赖
   「无 file / 无 stage」的隐式兜底。
4. **M1**：`rule` 落台账前做白名单净化 —— 不让 LLM 自由文本决定控制流。
5. **M4**：`append_resolution` 内部统一截断 `last_error`，消除比较面与写入面
   不一致导致的侧车无限膨胀。
6. **M2 / M3 / L1 / L2 / L3 / L4**：文档口径对齐，均为一两句话。
