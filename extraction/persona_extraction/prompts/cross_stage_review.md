# 跨阶段连贯审校

你现在接手本地项目 Offpage，你没有任何额外背景知识，请完全按本提示词执行。

## 任务卡

- **当前目标**: 对 `{work_id}` 的 **{subject_label}** 做跨阶段连贯性审校
- **审校对象**: `{subject}`（类型：{subject_kind}）
- **阶段范围**: `{stage_span}`（本窗口 {stage_count} 个阶段{window_note}）
- **输出**: 仅一个 JSON 数组（见 §输出格式），不要写文件、不要修改任何文件

## 你在整条流水线中的位置

每个阶段的**单文件**内容此前已被逐份全文审校过一遍——单文件内部的
事实错误、字段矛盾、schema 违规都已由那一轮负责。**不要重做那件事。**

你是全流水线里**唯一同时看到多个阶段**的环节。因此只找一件事：
**只有把相邻/多个阶段放在一起才能发现的断裂。**

单看某一个阶段块就能判定的问题，**不属于本次范围**，不要报。

## 输入

下面是按阶段顺序排列的**投影时间线**。它是从每个阶段快照里抽取
连贯性相关字段拼成的**精简视图**，不是完整文件：

- 每个阶段一个 `### {{stage_id}} — {{stage_title}}` 块
- 块内每行都标注了内容来源的 `json_path`（如 `$.character_arc`、
  `$.relationships`），数组元素带 `[i]` 下标
- 未出现在投影里的字段（语气示例、行为示例、边界文本、失败模式等）
  本次不审——它们无法单独构成跨阶段矛盾

```
{projection}
```

## 要找什么（跨阶段断裂）

1. **弧线自相矛盾**：`$.character_arc` 与后续阶段的 `$.stage_delta`
   / `$.current_status` 互相打架；或 arc 描述的走向与实际阶段序列相反。
2. **不可逆量倒退**：修为/境界、已达成的重大成就、已获得的能力等**按
   设定不可逆**的量，在后续阶段变低或消失，且没有任何阶段记录解释
   （如被废、被封印）。
3. **关系数值无因跳变**：同一 `target_character_id` 的 `trust` /
   `intimacy` / `attitude` / `guardedness` 在相邻阶段之间大幅跳变，
   而该阶段的 `driving_events` 为 0 或与跳变方向不符。
4. **知识倒流**：某事实在阶段 N 已进入 `$.knowledge_scope.knows`，却在
   阶段 N+k 重新出现在 `does_not_know` / `uncertain`，且没有记忆被抹除
   / 封印一类的解释。
5. **状态接不上**：阶段 N 的 `$.current_status` 结束态与阶段 N+1 的
   起始描述矛盾（人在两地、伤势凭空痊愈或复发、同伴凭空出现或消失）。
6. **世界线冲突**（仅世界投影）：`$.current_world_state` /
   `$.stage_events` 在不同阶段对同一事实给出互斥陈述；已解决的
   `unresolved_questions` 又变回未解决。

## 判定纪律

- **证据必须来自投影本身。** 每条 issue 至少引用两个不同阶段的内容
  作为对照——只引一个阶段说明它是单文件问题，不属本次范围。
- **不确定就不报。** 叙事里合理的变化（成长、反转、隐瞒、误解）不是
  断裂。角色**主观认知**与客观事实不一致是本项目的设计（见数据分层），
  **不要**把它当矛盾报。
- **重叠阶段只报一次。** 窗口之间有一个阶段重叠，若断裂正好落在重叠
  阶段上，正常报即可，下游会按 `stage_id` + `json_path` 去重。
- **数量不设配额。** 没有断裂就返回空数组 `[]`。宁可少报，不要凑数。

## 输出格式

**只输出一个 JSON 数组**，不要任何解释性文字、不要 markdown 代码围栏
之外的内容。数组每个元素：

```json
[
  {{
    "stage_id": "S0NN",
    "json_path": "$.某个具体字段路径",
    "rule": "arc_contradiction | irreversible_regression | relationship_jump | knowledge_backflow | status_discontinuity | world_line_conflict",
    "severity": "error",
    "message": "一句话说明断裂是什么，并明确引用另一个阶段作为对照（例：S012 的 X 与 S015 的 Y 互斥）"
  }}
]
```

字段规则：

- `stage_id`：断裂**应当被修正**的那个阶段（通常是较晚的、写错的那个）
- `json_path`：该阶段快照里**具体到字段**的路径，数组元素要带下标。
  **不要**填 `$`——根路径无法定点修复，会被下游直接丢弃
- `rule`：从上面枚举里选一个，不要自创
- `severity`：`error`（确定的断裂）或 `warning`（可疑但有合理解释空间）
- `message`：中文，一句话，必须含对照阶段的 `stage_id`

无发现时输出：`[]`
